## 📲 多终端详细配置指南

### 一、小米电视 / 安卓电视盒子（TVBox / 影视仓）

1. 打开电视上的 **TVBox** 或 **影视仓**。
2. 遥控器点击 **设置** -> **配置地址**（或直播设置中的“配置”）。
3. 电视屏幕会弹出一个**二维码**和一个**局域网网址**（例如 `http://192.168.1.xxx:9978`）。
4. 手机连接同一家里的 WiFi，微信扫码打开该页面（或电脑浏览器访问该网址）：
   - 将上面的 **M3U 订阅直链** 粘贴到输入框中。
   - 点击 **确定 / 保存**。
5. 电视立即同步完成，返回直播即可换台观看！

> 💡 **电视端最佳体验设置（强烈建议）**：
> 在 TVBox / 影视仓的 **“设置” -> “直播设置”** 里，将**“超时换源时间”设置为 3 秒**。
> *效果*：遇到任何线路网络波动时，电视会在 3 秒内自动无缝切换到下一条备用线路，彻底避免黑屏等待！

---

### 二、手机端（iOS / Android / SenPlayer）

1. 打开手机上的 **SenPlayer**（或 APTV / 任意 IPTV 播放器）。
2. 点击底部菜单栏 **“网络”**（或资料库） -> 点击右上角 **`+`** 按钮。
3. 在弹出的列表中选择 **“IPTV”**（添加 M3U 订阅）。
4. 填写订阅信息：
   - **名称**：例如 `CY精选电视`
   - **URL**：粘贴上面的 **M3U 订阅直链**
   - **EPG**：可留空（M3U 内已自动绑定好官方节目单与台标）
5. 点击 **保存**，立即呈现清晰分组，支持画中画小窗播放与锁屏后台收听！

---

### 三、电脑端（Windows / Mac）

- **本地极简网页秒播（免装任何软件）**：
  直接双击项目内的 [`tools/player.html`](tools/player.html) 用浏览器打开，左侧选台，右侧直接观看。
- **专业播放器（PotPlayer / VLC）**：
  直接将本地项目内的 [`tv/favorites.m3u`](tv/favorites.m3u) 鼠标右键选择通过 PotPlayer / VLC 打开即可换台播放。
